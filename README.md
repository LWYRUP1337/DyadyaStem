# Веб-сервис для сольной практики музыкантов

Сервис позволяет загружать треки, автоматически разделять их на отдельные музыкальные дорожки с помощью нейросетей, зацикливать фрагменты и настраивать автоматическое ускорение (Speed Ramp).

## Краткая архитектура

* **Frontend:** React + TypeScript + Vite (Port: `5173`)
* **Backend:** FastAPI (Port: `8000`)
* **Database:** PostgreSQL (Port: `5433` локально)
* **Storage:** Garage S3-compatible storage (Port: `3900`)
* **Queue:** Redis (Port: `6379`) + Celery
* **Worker:** Demucs AI runner (разделение аудио на стемы)

## Быстрый старт

cp .env.example .env
docker compose up --build

Чтобы сэкономить оперативную память и ресурсы процессора, запускайте только нужные сервисы (бэкенд, фронт, БД, S3, редис), то есть без воркера
